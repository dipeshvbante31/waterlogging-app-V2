Confidence is not probability

The class scores the model can output are uncalibrated: a score of 0.8 does not mean an 80% chance of waterlogging. {% if t.brier_score is defined %}For reference, the multiclass Brier score on the test period is {{ f3(t.brier_score) }}{% if t.log_loss is not none %} and the log loss is {{ f3(t.log_loss) }}{% endif %} (lower is better).{% endif %} The app therefore never presents them as probabilities.
